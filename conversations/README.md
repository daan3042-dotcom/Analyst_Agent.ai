# Original Development Chat

This folder is where the full export of the original Claude conversation
this project was built in should live, per the migration plan (Step 1:
"veiligstellen" — safeguard the original chat before anything else).

**This step requires you, not Claude** — exporting chat history is a
Claude.ai account action:

Settings → Privacy → Export data

Once you have the export, place the relevant conversation file here
(rename it to `original-development-chat.md` or similar) and commit it.
It's excluded from nothing in `.gitignore`, so it will be tracked once
added — this is intentional; it's meant to be the permanent historical
record backing everything in `docs/`.
